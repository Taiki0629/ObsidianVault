`03_drafts/` の指定ノートを Qiita 投稿用に整形する。`$ARGUMENTS` がファイル名。

## チェックリスト

ノートを読んで以下を順に修正:

1. **画像記法の変換**
   - `![[image.png]]` → `![image.png](./image.png)` 形式に。
   - パスは Qiita 上で動くよう調整(現状は Qiita 側で画像を別途アップロードする想定でローカルパスのまま残してもよい。後工程の手作業を想定して `<!-- TODO: Qiita で画像を再アップロード -->` を付ける)。
2. **内部リンクの処理**
   - `[[他ノート]]` は Qiita 上で意味を持たないため、説明文に展開するか削除する。Qiita 公開済みノートへの参照なら `qiita_url` を本文中に URL として展開する。
3. **コードブロックの言語タグ**
   - ` ``` ` のみのブロックを見つけたら、文脈から推測した言語タグを付ける(`bash`, `python`, `typescript`, `yaml` など)。推測できないものはユーザーに確認。
4. **タグ整理**
   - frontmatter の `tags` が 5 個を超えていたら、Qiita 用に重要度上位 5 個を別フィールド `qiita_tags: [...]` として追加。元の `tags` は vault 内検索のため残す。
5. **トーン微調整**
   - 一人称メモ調(「〜と思った」「〜してみた」)は読者向けの言い切り調に調整。ただし著者の主観・体験は価値なので削らない。
   - 冒頭に「TL;DR」が無ければ 3 行以内で追加。

## 出力

- 変更した行の概要を箇条書きで報告。
- frontmatter の `updated` を今日に。`status` は `draft` のまま。
