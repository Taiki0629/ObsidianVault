# アイデア作成スキル

「$ARGUMENTS」を起点に、`10_Ideas/` に「型のできたアイデアノート」を作成する。
空テンプレを置くのではなく、**テーマに合わせて問い・切り口・想定アウトプットまで埋めてから**渡すこと。

## 手順
1. `10_Ideas/` を Glob し、既存ノートの連番を確認する（命名は `NNN_タイトル.md` 形式、ゼロ埋め3桁）。
2. `${CLAUDE_SKILL_DIR}/template.md` を土台に、テーマに合わせて各セクションを埋める。
   - ファイル名: `10_Ideas/NNN_テーマを表す簡潔なタイトル.md`
3. frontmatter を埋める（`title / created / updated` は本日、`status: idea`、`tags` に `#status/idea` と `#topic/分野`）。
4. 中身を以下の観点で具体化する（**ここがこのスキルの肝**）:
   - **中心の問い**: そのテーマで一番面白い／知りたい問いを1つに絞って言語化する。
   - **切り口**: 異なる角度を3〜5個出す（例: 仕組み / 比較 / 実例 / 落とし穴 / 将来性）。テーマに合うものを選ぶ。
   - **仮説・直感**: 現時点での自分の見立て（後で調査で検証する叩き台）。
   - **想定アウトプット**: 記事向きか動画向きか、誰に何を伝えるか。
   - **調査で確かめたいこと**: investigate に渡せる具体的な問いを箇条書きで。
5. 関連しそうな既存ノート（10〜30）を Grep し、あれば `related` に `[[ウィキリンク]]` を張る。

## 厳守事項
- 問い・切り口はテーマに固有のものにする。汎用的な穴埋めの言葉で済ませない。
- この段階では Web 調査はしない（事実確認は investigate の役割）。あくまで仮説と問いの整理に留める。
- 「調査で確かめたいこと」は、そのまま `/investigate` に渡せる粒度にする。

## 次のアクション
作成後、「このアイデアを調査するなら `/investigate <テーマ>`」と一言添える。
